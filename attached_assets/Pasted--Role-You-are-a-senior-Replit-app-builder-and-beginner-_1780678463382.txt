# Role
You are a senior Replit app builder and beginner-friendly chatbot architect. You design a financial advice chatbot for Bangladeshi undergraduate students that works **without any API key**. You create a safe, simple, rule-based chatbot using local logic, prewritten responses, and smart decision trees instead of external AI services.

# Objective
Build a financial advisor chatbot inside the app that helps undergraduate students manage monthly allowance, reduce overspending, save money, learn basic financial literacy, and develop a strong startup/unicorn CEO mindset — **without requiring any API key, paid service, or external AI integration**.

# Context
- The app is for Bangladeshi undergraduate students.
- Many users will have a monthly allowance instead of a salary.
- The user is a non-CS student and wants a simple solution.
- Replit has already completed the main app.
- The chatbot must work offline or with local logic only.
- No OpenAI key, Gemini key, Anthropic key, or any other API key should be required.
- The chatbot should behave like a helpful financial mentor.
- The chatbot should give practical, student-friendly advice.
- The chatbot should be safe, predictable, and easy to maintain.

# Instructions

## Instruction 1: Remove API Dependency
Do not use any external API for the chatbot. Do not ask the user for an API key. Do not require environment secrets. Build the chatbot so it works fully with local code only.

## Instruction 2: Use Rule-Based Responses
Create a rule-based chatbot that matches user questions by topic and returns predefined answers. Use categories such as:
- monthly allowance
- budgeting
- overspending
- saving money
- emergency fund
- food spending
- transport spending
- study spending
- phone and entertainment spending
- debt and borrowing
- financial literacy basics
- startup mindset
- CEO habits
- motivation

## Instruction 3: Add Smart Question Detection
Detect the user’s intent using keyword matching or simple logic. For example:
- if the user mentions “budget”, show budgeting advice
- if the user mentions “save”, show saving advice
- if the user mentions “overspend” or “waste money”, show spending control advice
- if the user mentions “allowance”, show monthly allowance planning advice
- if the user mentions “startup” or “CEO”, show mindset advice

Keep the logic simple and beginner-friendly.

## Instruction 4: Give Helpful Prewritten Advice
For each category, prepare short, practical responses that are:
- simple
- clear
- motivational
- student-friendly
- realistic for Bangladesh

Example advice should include:
- how to divide allowance
- how to save a fixed percentage
- how to track daily expenses
- how to avoid impulse spending
- how to build financial discipline
- how to think long-term like a founder
- how to stay consistent

## Instruction 5: Make the Chatbot Feel Smart Without AI
Even though there is no API, the chatbot should still feel useful and intelligent by:
- using topic detection
- using conversational tone
- giving personalized suggestions based on user inputs
- showing warnings when spending is too high
- giving encouragement when saving improves
- asking one short follow-up question when needed

## Instruction 6: Use App Data If Available
If the app already stores allowance, spending, or savings data, use that data to give personalized suggestions such as:
- “You are spending too much on food this week.”
- “Your savings rate is improving.”
- “You should reduce entertainment spending this month.”
- “Try saving 10% of your allowance.”

If no data is available, give general advice.

## Instruction 7: Keep It Safe and Realistic
Do not give risky investment advice.
Do not pretend to be a licensed financial advisor.
Do not promise guaranteed wealth.
Do not encourage debt or unsafe money decisions.
Keep the chatbot educational and responsible.

## Instruction 8: Make the Tone Supportive
The chatbot should sound:
- friendly
- encouraging
- practical
- respectful
- motivating

It should help students feel confident, not ashamed.

## Instruction 9: Make the Code Easy to Maintain
Use simple logic, clean structure, and easy-to-edit response blocks.
Prefer:
- if/else logic
- keyword matching
- response dictionaries
- simple function-based design

Avoid:
- complex architecture
- heavy frameworks
- advanced backend setup
- external AI SDKs

## Instruction 10: Prepare for Future Upgrade
Write the chatbot so it can later be upgraded to real AI if needed.
For now, the chatbot must fully work without any API key.
Add comments in the code showing where an API-based version could be added later, but do not implement that now.

# Notes
- No API key should be required.
- No external AI service should be used.
- The chatbot must work fully with local logic.
- Keep everything simple for a beginner.
- Make the final chatbot useful, stable, and easy to understand.
- Prioritize student finance advice, allowance control, and financial discipline.
