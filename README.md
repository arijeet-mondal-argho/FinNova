# FinNova

FinNova is a beginner-friendly financial management and financial literacy app designed for Bangladeshi undergraduate students. It helps users manage monthly allowance, track spending, build saving habits, learn money basics, and stay motivated with a startup/CEO mindset.

## Features

- Monthly allowance tracking
- Expense categorization
- Savings goal planning
- Spending summaries
- Financial literacy tips
- Student-friendly budgeting guidance
- Startup and unicorn-CEO mindset content
- Built-in chatbot financial advisor
- Mobile-first UI
- Beginner-friendly design

## Why FinNova?

Many undergraduate students in Bangladesh receive a monthly allowance but do not have a simple system to manage it. FinNova is built to solve that problem by making money management easy, practical, and motivating.

The app is also designed to inspire students who want to think beyond money management and build the mindset needed for entrepreneurship and high-growth startups.
